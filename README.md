# 最后笑的人 / Last Laugh Club

三段独立的竖屏互动视频短剧，共享“公众先判错、最后公开改口”的情绪母题：被诬陷的服务员让香槟作证，被看低的裁缝让雨评价礼服，被婚礼抹去的父亲让旧音乐盒选择舞伴。

```bash
npm install
npm run dev
npm run build
```
