# 《最后笑的人》视觉文档

## 1. 视觉论点

“三份由公众当场改判的流媒体短片”。影像是主角，UI 像一套克制、锋利的独立电影选集：纯黑、奶油白和一条番茄红判决线。三个场景在摄影上各有色温，但始终共享近距离面部、围观者手机和人群转向这一视觉语法。

它不沿用《迟到 99 分钟》的小报红黄，也不沿用《被偷走的聚光灯》的颁奖直播蓝金系统。玩家记住的画面应是“原本朝着主角的审判目光，在证据出现后整齐转向了另一个人”。

## 2. 构图与镜头

- 画幅：生成源为 9:16，实际视频约 768×1024；UI 裁切优先保护脸、核心证物与人群视线。
- 建立镜头：固定中广角，在 5 秒内从正常身份过渡到公开羞辱；选择停点必须同时包含主角、施压者和核心道具。
- 结果镜头：尽量保持人物站位，只移动戒指、托盘、雨水、名卡、音乐盒、视线和灯光。
- 人群不是装饰：失败时仍朝主角拍摄或背对主角；成功时必须把手机、镜头、身体或掌声转向真相。

## 3. 色彩系统

| Token | 色值 | 用途 |
|---|---:|---|
| `--llc-black` | `#070707` | 外层与媒体底色 |
| `--llc-ink` | `#131313` | 问题区和结果遮罩 |
| `--llc-cream` | `#F3EBDD` | 主文字与按钮底 |
| `--llc-red` | `#F04438` | 判错、进度线、失败 |
| `--llc-lime` | `#C9F45B` | 意外正确与通过 |
| `--llc-muted` | `#A79F93` | 次级信息 |

场景摄影：订婚宴为香槟金与酒红；时装晚宴为钴蓝与冷银；婚礼为暖琥珀与旧木色。UI 不跟随场景换主题色。

## 4. 排版

- 英文标题：Arial Narrow / DIN Condensed，900，全大写，36–58 px。
- 中文标题：PingFang SC，800，28–42 px。
- 问题：Inter / Arial / PingFang SC，800，17–24 px。
- 答案：同族 750，15–18 px，允许两行；英文短屏不得低于 14 px。
- 集数和状态：10–12 px，900，字距 0.12em。

标题允许略微越界裁切形成电影海报感，但答案、问题和状态文字不允许裁切。

## 5. 形状、材质与光

- UI 几何为直边与 1–2 px 线框，圆角最大 6 px；不使用漂浮圆角卡片。
- 按钮默认奶油白底黑字，按下压低 2 px 并变为番茄红边；成功使用青柠色小标，不用大面积霓虹。
- 媒体区保持摄影黑位，不叠玻璃模糊；字幕用黑色渐隐底而非气泡。
- 场景光线写实，有明确主光；禁止 AI 常见的全脸均匀柔光和无来源辉光。

## 6. 素材清单与连续性

- 三套完全独立的固定演员、服装、地点和道具锚点。
- 每段：`setup_start.webp`、`setup.mp4`、`choice.webp`、三条结果 MP4、三张 `_end.webp`。
- 第一段必须始终只有一枚银色戒指；第二段只出现一条 Mara 的钴蓝礼服与一条 Beatrice 的纸质礼服；第三段音乐盒、名卡和三名核心人物固定。
- 正式海报表现三个主角被同一条红色“误判线”切开、又同时抬头的统一构图；只允许英文标题，不出现中文、UI 或东方化人物。

## 7. UI 与图标

- 屏幕状态：封面、建立演出、问题、结果演出、结算。
- 顶栏只显示三枚短划线进度、当前 `STORY 1/3` 与声音 SVG；不显示分数、技术标签或剧情树。
- 问题页只显示媒体停点、8–16 字冲突、一句问题和三个答案。
- 声音图标使用统一 24×24 线性 SVG；箭头使用同族 SVG。禁止 Emoji 功能图标。

## 8. 动效与反馈

- 输入：按钮同帧压下，80–140 ms；随后立即切到静帧承接的视频页。
- 视频就绪：180 ms 淡入；加载态不闪烁布局。
- 失败：红色判决线从左扫入，停 220 ms 后显示后果；不使用屏幕震动。
- 成功：青柠细线穿过旧判词并替换为夺回的身份词，260 ms。
- 第三段 10 秒终局不给额外粒子，把注意力留给音乐盒、女儿转身和父女舞。
- `prefers-reduced-motion` 时关闭 UI 位移，只保留透明度和视频本身。

## 9. 参考转译

- 借鉴流媒体短剧的“一张强图 + 一句冲突 + 三个立即可懂的选项”，不复制任何平台品牌、Logo 或版式。
- 借鉴时尚杂志的窄体标题和高对比黑白，但将红线定义成“公众误判”的叙事道具，而非装饰。
- 借鉴短视频里围观手机、瞬间安静和镜头转向的群体态度表达，不依赖弹幕或字幕解释。

## 10. 禁止模式

- 三段都用同一办公室、同一坏老板或同一荒诞道具；
- 只有主角表情变化，人群和施压者没有反应；
- 结果必须读字幕才知道戒指、资格或关系已经归还；
- UI 同时显示故事简介、任务、正确率、收藏、进度树等多层信息；
- 使用渐变玻璃卡、圆润 AI App 按钮、Emoji、漫画拟声词；
- 生成演员跨镜头换脸、换肤色、换服装，或同一戒指出现两枚；
- 正式海报出现中文或东方化角色。

## 11. 垂直切片验收

先完成第一段《让香槟作证》：

- 5 秒建立片在静音状态能看出 Olivia 藏戒指、公开指控、经理倒空 Elena 小费袋；
- 选择停点同时看见 Elena、Olivia、经理、香槟杯和围观手机；
- 成功片只做“托盘靠近 → 戒指出现 → 人群转向 → 小费袋归还”一条动作链；
- 两个失败分别体现无效自证和屈辱加深，不复用视频；
- 390×844 与 320×568 三个答案全部可见、目标 ≥44 px；
- 第一轮 QA 无 P0/P1 后，才扩展第二、三段。
