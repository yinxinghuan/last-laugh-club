# 《最后笑的人》需求文档

## 1. Overview

一款 2–4 分钟完成一次的竖屏互动视频短剧选集：三个互不相关的普通人分别遭遇公开诬陷、阶层羞辱和亲密关系抹除，玩家每段从三个冲动中寻找唯一“不像正常答案”的行动，让同一群见证者亲眼推翻最初判断。三段共享“他们先判错了你”的情绪母题，但人物、地点、道具和情绪释放方式完全独立。

本作专门验证：一款游戏可以用三段短小品保持统一情绪承诺，而不必把每段硬接成连续故事。删除磁力托盘、雨墙和音乐盒后，三个现实困境仍必须成立。

## 2. Visual Design

- 第一段《让香槟作证》：西方豪华屋顶订婚宴；Elena 是年轻拉丁裔女服务员，Olivia 是白人社交媒体名媛，经理为中年白人男性。核心道具是银色戒指、香槟杯与深色金属托盘。
- 第二段《让雨来评价》：西方时装慈善晚宴；Mara 是年轻黑人女裁缝，Beatrice 是年长白人时装编辑。核心道具是钴蓝手工礼服、香槟污渍与室内雨幕装置。
- 第三段《让音乐盒选择》：西方酒店婚礼舞池；Luis 是 55 岁拉丁裔父亲，Emma 是成年新娘，Richard 是富裕白人继父。核心道具是旧木质音乐盒与被拿走的父女舞名卡。
- 影像采用写实商业短剧摄影；UI 使用黑色流媒体选集界面、番茄红判决线与奶油白字幕。问题页仅保留集数、冲突、一句问题和三个答案。
- 目标视口为 390×844 与 320×568；不使用整页缩放。

完整视觉合同见 `doc/visual.md`。

## 3. Game Mechanics

### 初始化参数

- 小品数：3；每段人物和地点独立。
- 每段答案：3；每次失败重试循环换位。
- 每段成功答案：1；失败答案：2。
- 每段建立视频：5 秒；建立尾帧与选择停点一致。
- 普通结果：5 秒；第三段温暖终局：10 秒。
- 失败播放完整结果后重试当前段；成功进入下一段；三段成功后回到封面。
- 点击即时反馈不超过 80 ms；媒体未就绪时保留静帧和明确加载态。

### 共享情绪合同

三段都遵循：

`正常身份 → 众目睽睽下被误判/贬低 → 选择替主角释放冲动 → 证据以意外方式出现 → 原见证者改变动作与站位 → 主角夺回清白、资格或关系`

共同点必须是情绪机制，不是相同反派、相同机器人或相同办公室。三段的偿还方式分别为清白、专业价值和亲密关系。

### 第一段：让香槟作证

- 建立：Elena 正常服务订婚宴；Olivia 趁人不注意把自己的戒指滑进香槟，随即指控 Elena 偷窃；经理当众倒空 Elena 的小费袋，客人举起手机拍摄。
- 成功选项：**“让香槟自己作证。”**
- 成功结果：Elena 把金属托盘举到所有酒杯下，Olivia 杯底的戒指被吸出并清脆落在托盘上；手机镜头转向证物和 Olivia，经理当众向 Elena 摊开手掌道歉。
- 两个失败：当众掏空口袋仍被带走；跪下搜索地面让客人更相信 Olivia。
- 情绪变化：正常工作 → 被诬陷和围观 → 物证公开反咬诬陷者 → 清白归还。

### 第二段：让雨来评价

- 建立：Mara 穿着亲手做的钴蓝礼服进入慈善时装晚宴；Beatrice 指着她说“廉价”，故意把香槟泼在礼服上，摄影师和宾客发笑。
- 成功选项：**“让雨来评价这条裙子。”**
- 成功结果：Mara 走进场馆雨幕装置，礼服遇水绽放出明亮花纹并保持挺括；Beatrice 的纸质高级定制软塌变形，摄影师全部转向 Mara，编辑把前排通行证交给她。
- 两个失败：披外套遮住污渍后被安排去衣帽间；把香槟泼回去后被保安带走。
- 情绪变化：被阶层和外表否定 → 主动接受更严苛检验 → 专业能力公开胜出 → 获得入场资格。

### 第三段：让音乐盒选择

- 建立：Luis 原本准备与女儿 Emma 跳父女舞；富裕继父 Richard 当众取走 Luis 的名卡，嫌他的旧西装“破坏照片”，主持人改请 Richard 上场，Emma 犹豫却未反抗。
- 成功选项：**“让旧音乐盒选择她的舞伴。”**
- 10 秒结果：Luis 上紧旧音乐盒 → Emma 听出童年摇篮曲并停下 → 她穿过人群牵起 Luis → 主持人把父女舞名卡重新放回 → 全场围成圆圈鼓掌，Richard 独自留在熄暗的舞台边。
- 两个失败：大喊“我是她亲生父亲”让 Emma 当场落泪；悄悄离开让 Richard 完成父女舞。
- 情绪变化：亲密关系被金钱和体面抹除 → 共同记忆作证 → 女儿主动选择 → 关系公开恢复。

### 状态模型

```text
cover → setup-video → question → result-video → verdict
                    ↑               |           |
                    └── sketch retry ───────────┘
                                    └── success → next sketch / anthology finale
```

## 4. Controls

- Pointer / Touch：开始、三个答案、重试、继续使用 `onPointerDown`，触控目标不小于 44×44 CSS px。
- Keyboard：Enter 开始/继续；1–3 选择当前屏幕顺序；M 静音。
- 视频使用 `playsInline`；建立视频结束后才开放选择。
- iOS 全局禁止长按菜单、图片拖拽与非编辑文本选择。

## 5. Win / Lose Conditions

- 每段选中唯一成功答案并看完结果即通过；三段全部通过即完成选集。
- 失败必须有独立 5 秒因果结果，并明确显示主角失去的清白、资格或关系；不能只显示 Failed。
- 成功必须在遮住结果文字时仍看得出原见证者改变站位或动作，以及主角具体夺回了什么。
- 三段的反转媒介必须不同；如果只是在不同场景让同一奇观出现，判为结构验证失败。

## 6. Sound Effects

- 视频使用随片 AAC 声轨；每段建立和结果都包含环境、人群反应与关键道具声。
- 第一段成功：戒指落盘的高频金属声在 3–4 秒成为峰值，随后手机快门停止并出现一拍安静。
- 第二段成功：雨幕声从 1 秒渐强，花纹显现时加入快门连拍和人群吸气声。
- 第三段成功：音乐盒音色贯穿 10 秒，6 秒后叠加掌声，9–10 秒形成温暖峰值。
- 静音状态仍可仅靠动作理解；声音按钮即时改变视频 `muted` 并持久保存偏好。
